Como jogarx
Clique no chão para andar (segure para continuar andando).
Clique num monstro para atacar sem parar. Clique num item para pegar. Clique num NPC para conversar.
F1–F9 ou 1–9: barra de atalhos. Arraste itens e habilidades ativas para ela; botão direito limpa.
A status · E itens · S habilidades · X sentar · Enter conversar · Esc fecha janelas

Não há classes. Cada habilidade tem nível de 0 a 100 e sobe com o uso:
· lute com uma arma para treinar aquela arma e a Força;
· acerte golpes para treinar Destreza; esquive e ande para treinar Agilidade;
· leve dano para treinar Resistência; gaste SP para treinar Inteligência;
· use magias de um elemento para treinar aquele elemento.
Ninguém começa com habilidades ativas: aprenda técnicas físicas na Galpão de Treino e magias na Cabana da Sábia, pagando em cobres. Cada uma exige um nível mínimo.
Pegue e entregue missões na Guilda dos Aventureiros para ganhar cobres, itens e subir de rank.

Elementos: Água › Fogo › Terra › Ar › Água · Luz ⇄ Sombras. Mesmo elemento causa metade do dano.
O jogo salva sozinho no navegador.
